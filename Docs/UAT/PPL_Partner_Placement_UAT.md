## 4. السيناريوهات

اكتب النتيجة: نجح / فشل / معلّق، وأي ملاحظة.

### إنشاء ومراجعة (شريك أ)

| المعرّف | الخطوات | النتيجة المتوقعة | النتيجة | ملاحظات |
|---|---|---|---|---|
| UAT-01 | القائمة الجانبية ← تحديد المستوى | تظهر القائمة بهوية الشريك، أو رسالة «لا توجد اختبارات» مع زر الإنشاء | | |
| UAT-02 | إنشاء متقدم: اختر الدورة والدفعة، ووزّع أسئلة لا تساوي الإجمالي | رسالة واضحة بالفرق، ولا يُنشأ اختبار | | |
| UAT-03 | صحّح التوزيع واحفظ | تفتح صفحة المراجعة، والاختبار مسودة، ولا يراه أي طالب | | |
| UAT-04 | استبدل سؤالًا، وأضف سؤالًا من البنك، وعاين سؤالًا | يتغير السؤال، والعدد الإجمالي صحيح، والمعاينة تعرض السؤال | | |
| UAT-05 | فعّل «لا أعرف الإجابة» | رسالة نجاح، ويظهر الخيار للطالب لاحقًا | | |
| UAT-06 | أنشئ من نموذج احترافي | يصل الاختبار مباشرة لطلاب الدفعة مع إشعار | | |
| UAT-07 | أخفِ مسودة ثم استرجعها، ثم احذف أخرى نهائيًا | تأكيد قبل الحذف، وتنفذ كل عملية برسالة | | |

### الإرسال وحل الطالب

| المعرّف | الخطوات | النتيجة المتوقعة | النتيجة | ملاحظات |
|---|---|---|---|---|
| UAT-08 | شريك أ: تأكيد الإرسال ثم إرسال، مع نقر مزدوج سريع | إرسال واحد، وعدد الطلاب صحيح | | |
| UAT-09 | طالب أ1: افتح الإشعار ولوحة تحديد المستوى | يظهر الاختبار بزر **«بدء الاختبار»** لا «استكمال» | | |
| UAT-10 | طالب ب1: افتح لوحته | لا يظهر اختبار شريك أ | | |
| UAT-11 | طالب أ1: ابدأ، وأجب، وتنقّل، وأعد تحميل الصفحة | تبقى الإجابات والوقت المتبقي صحيحًا | | |
| UAT-12 | طالب أ1 أثناء الحل: افتح في تبويب آخر رابط النتيجة أو المراجعة | عودة للوحة مع رسالة، ولا تظهر الإجابات الصحيحة | | |
| UAT-13 | طالب أ1: سلّم، ثم عد للصفحة القديمة وغيّر إجابة | رسالة «تم تسليم هذا الاختبار» وتحويل للنتيجة، والدرجة لا تتغير | | |
| UAT-14 | طالب أ2: ابدأ واترك الوقت ينتهي | تسليم تلقائي وتظهر النتيجة | | |
| UAT-15 | اختبار حضوري: أدخل كودًا خطأ 3 مرات ثم الكود الصحيح | رسالة خطأ ثم دخول | | |
| UAT-16 | شريك أ: أضف طالبًا جديدًا للدفعة ثم «إرسال للطلاب الجدد» | يصل له فقط | | |
| UAT-17 | شريك أ: أعد الإرسال لطالب أ2 | تُمسح محاولته ويبدأ من جديد، ويصله إشعار | | |

## 8. مشكلات معروفة

- الإجابات في صفحتي الأدمن المذكورتين في UAT-27 تُعرض نصًا بلا تنسيق.
- الشريك يستطيع تغيير خيار «لا أعرف» بعد الإرسال، كما في الأدمن.
- إخفاء اختبار **المعهد** لا يخفيه عن الطالب رغم نص الرسالة (لا يخص اختبارات الشركاء).
- إعادة الإرسال من **الأدمن** تترك التعيين القديم فيتكرر الاختبار في لوحة الطالب (لا يخص الشركاء).
