# حزمة اختبار قبول المستخدم (UAT): إرسال الأدمن للمدارس الشريكة (APD)

> ينفذها مراجعون من المعهد ومن مدرستين تجريبيتين. النتيجة وقرار الإطلاق لهم، والخانات الفارغة تُملأ أثناء الاختبار.
> النطاق: خمس شاشات إرسال في الأدمن (واجب من نموذج، اختبار من نموذج، تحديد المستوى، مؤشر الأداء، معمل القياس)، وصفحات المتابعة الجديدة عند المدرسة، وسجل الإرسال.

## 4. السيناريوهات

اكتب النتيجة: نجح / فشل / معلّق، وأي ملاحظة.

### اختيار الجمهور (مشترك في الشاشات الخمس)

| المعرّف | الخطوات | النتيجة المتوقعة | النتيجة | ملاحظات |
|---|---|---|---|---|
| UAT-01 | افتح أي شاشة إرسال واترك «دفعات المنصة» | تظهر دفعات المعهد فقط، ولا تظهر أي دفعة مدرسة. الإرسال يعمل كما قبل التطوير | | |
| UAT-02 | اختر «المدارس الشريكة» قبل اختيار النموذج/المنهج/الكورس | تنبيه «اختر … أولًا» بلا تحميل | | |
| UAT-03 | اختر المصدر ثم «المدارس الشريكة» | تظهر أ وب مؤهلتين حسب العقد، وج معطّلة بسبب «لا عقد نشط»، والدفعات محددة افتراضيًا ويمكن إلغاء بعضها، والعدّاد صحيح | | |
| UAT-04 | أدمن بلا إرسال للمدارس: افتح نفس الشاشة | لا يظهر خيار «المدارس الشريكة» | | |
| UAT-05 | أدمن كامل: اختر مدرسة غير مؤهلة لنوع ما، فعّل «تجاوز العقد» بسبب أقل من 10 أحرف | رسالة تطلب سببًا من 10 إلى 500 حرف | | |
| UAT-06 | أدمن إرسال فقط: نفس الحالة | لا يظهر خيار التجاوز، والمدرسة غير المؤهلة لا تُختار | | |
| UAT-07 | جوال 375px: شاشة إرسال بقائمة مدارس طويلة | البحث و«تحديد الكل» يعملان، ولا تمرير أفقي | | |

### الإرسال لكل نوع

| المعرّف | الخطوات | النتيجة المتوقعة | النتيجة | ملاحظات |
|---|---|---|---|---|
| UAT-08 | واجب من نموذج إلى أ (ب غير مؤهلة للواجبات) | صفحة نتيجة: أ نجح. يظهر في `Partner/SentHomeworks` لدى أ بوسم «مرسل من المعهد»، ولا يظهر في `ModelAssignments` بالأدمن | | |
| UAT-09 | اختبار من نموذج إلى أ وب | اختبار مستقل لكل مدرسة، يظهر في «الاختبارات المرسلة» لكل منهما، ولا يظهر للأدمن | | |
| UAT-10 | تحديد مستوى إلى أ «إرسال فوري» | يصل لطلاب أ النشطين فقط، لا للمنسحب | | |
| UAT-11 | تحديد مستوى إلى أ «مسودة لدى المدرسة» | لا يصل لأي طالب حتى ترسله أ من منطقتها. ب مرفوضة حتى مع التجاوز لأن عقدها لا يشمل تحديد المستوى | | |
| UAT-12 | مؤشر الأداء إلى أ (منهج + دفعات) ← صفحة المراجعة ← إرسال | نسخة لكل مدرسة برمز مرجعي مختلف، والقالب يظهر في أرشيف الأدمن بوسم «قالب إرسال للشركاء» | | |
| UAT-13 | معمل القياس: إسناد لدفعات أ وب | يظهر في `Partner/MinistrySimExams` لكل مدرسة بدفعتها فقط، ولا يظهر في `MinistrySimExamAssignments` بالأدمن | | |
| UAT-14 | معمل القياس: إسناد فردي لطالب أ1 تحت «المدارس الشريكة» | يُقبل لطالب من فروع أ فقط | | |
| UAT-15 | (بمساعدة الفريق التقني على بيئة الاختبار) أرسل لمدرستين مع إفشال إرسال إحداهما | صفحة النتيجة تقول صراحة: نجح لدى واحدة وتعذر لدى الأخرى، وما نجح لا يحتاج إعادة | | |
| UAT-16 | نقر مزدوج سريع على زر الإرسال | إرسال واحد فقط لكل مدرسة | | |

| المعرّف | الخطوات | النتيجة المتوقعة | النتيجة | ملاحظات |

| UAT-17 | طالب أ1: افتح الواجبات والاختبارات وتحديد المستوى ومؤشر الأداء ومعمل القياس | كل ما أُرسل يظهر بنفس الصفحات المعتادة ويُحل حتى النهاية | | |

| UAT-19 | مدرسة أ: «إعادة الإرسال» في مؤشر الأداء لطالب بدأ ولم ينهِ، ثم لطالب أنهى | الأول يعود له الوقت مع بقاء إجاباته، والثاني مرفوض برسالة | | |

## 8. مشكلات معروفة

- ما أُرسل قبل هذا الإصدار يبقى ملك المعهد ويظهر للأدمن كما كان، بما فيه واجبات أرسلتها المدارس من مسوداتها قبل APD.
- سجل الإرسال يكتب ما أرسله الأدمن فقط. مسودة تحديد المستوى تُسجَّل بصفر طلاب، وإرسال المدرسة لها لاحقًا يغيّر حالتها في السجل دون تسجيل عدد الطلاب.
- إرسال المدرسة لمسودتها قد يصل لطالب منسحب، لأن نطاق المدرسة لا يفحص حالة التسجيل. سلوك قديم لكل إرسال المدارس، وينتظر قرارًا.
- لا PDF من الخادم لتقرير ولي الأمر في معمل القياس عند المدرسة؛ الطباعة من المتصفح.
- هدف الأداء (20 مدرسة في أقل من 30 ثانية) لم يُقَس على بيانات بحجم الإنتاج.
