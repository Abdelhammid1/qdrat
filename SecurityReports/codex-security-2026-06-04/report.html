Findings

1. Partner tenant can be selected without authentication

Severity: Critical. Confidence: High.

PartnerContextController.Set(int partnerId) stores any existing partner ID in session without authentication, authorization, or CSRF. Multiple Partner controllers trust that session value through PartnerBaseController.

Affected: Areas\Partner\Controllers\PartnerContextController.cs:45, :51, PartnerBaseController.cs:18, StudentsController.cs:42.

2. Production Azure SQL credentials are committed in config

Severity: Critical. Confidence: High.

appsettings.Production.json:3 contains production Azure SQL host, username, and plaintext password. Rotate immediately and move to secure configuration.

3. Hangfire dashboard is mapped without explicit authorization

Severity: High. Confidence: Medium.

Program.cs:914 maps app.UseHangfireDashboard() without visible dashboard authorization options.

4. Student study-session workflows are unauthenticated and object IDs are trusted

Severity: High. Confidence: High.

StudySessionsController and SessionRatingsController lack controller-level authorization and use direct object IDs without ownership checks.

5. Student AI recommendations expose arbitrary student performance by studentId

Severity: High. Confidence: High.

AIRecommendationController.Index(int studentId) queries performance data by attacker-controlled student ID.

6. Generic unauthenticated PDF rendering endpoint accepts arbitrary view names

Severity: High. Confidence: Medium.

PrintController.ViewAsPdf accepts user-controlled view and route values without authorization.

7. Impersonation cookie is not marked Secure in production code

Severity: Medium. Confidence: High.

Services\ImpersonationService.cs:38 sets Secure = false for a sensitive impersonation state cookie.

8. Identity password and session policy are weak for production

Severity: Medium. Confidence: High.

Program.cs:146-152 disables most password complexity requirements and allows length 6; session timeout is 6 hours.

9. Vulnerable transitive NuGet packages are present

Severity: Medium. Confidence: High.

NuGet audit reported vulnerable transitive packages including Microsoft.Build 17.8.3, Npgsql 8.0.0, System.Data.SqlClient 4.4.0, and System.IO.Packaging 6.0.0.

Minimum Release Gate

  1. Fix Partner authorization and tenant binding.
  2. Rotate and remove production database credentials from repository/config.
  3. Protect or disable Hangfire dashboard.
  4. Fix unauthenticated/IDOR student study-session and AI recommendation endpoints.
  5. Lock down generic PDF rendering.
  6. Re-run security smoke tests for anonymous, cross-student, cross-partner, and admin-only routes.
