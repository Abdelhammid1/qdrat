S8 — المسار الجديد + الشروط + ملء الشاشة + الصلاحيات (D19، D22، D27)

القصةما تم
S8.1الاجتياز يفتح التالي في نفس الطلب (OpenNextAxisAsync بلا respectSchedule). OpenPendingAxesAsync يعالج التسجيلات القديمة العالقة عند فتح الخطة/المحور. حُذفت الجدولة اليومية (RemedialTrackSchedule، SaveSchedule، واجهة «جدول الأيام»). عمود ReleaseDay باقٍ ومُهمَل (لا ترحيل هدّام). فتح الإدارة للمحور (AdminOpenNextAsync) كما كان.
S8.2Terms.cshtml مطابق للمسار الجديد (لا «لكل يوم» ولا «أسبوعان»).
S8.3ملء الشاشة: Fullscreen API (+WebKit) ثم بديل CSS rtk-pseudo-fs عند تعذّره (iPhone/WebView)؛ يخرج بالزر وEscape؛ العلامة المائية داخل الحاوية فتبقى ظاهرة. الملفات: remedial-track-player.js، student-rtk.css.
S8.4الأقسام الثلاثة (RemedialTracks، RemedialTrackPublications، RemedialTrackReports) في GetControllersCatalog فتظهر في مصفوفة البروفايل.
S8.5Migrations/Scripts/RTK_TermsAccepted.sql (يغلق ثغرة نشر).

S9 — الحذف الناعم + التعديل بعد النشر + السجل (D25، D26)

القصةما تم
S9.1حقول IsDeleted وبيانات الحذف على RemedialTrackPublication. DeleteAsync (سبب 5–300، نطاق الدفعة، Idempotent، لا يمس التسجيلات) وRestoreAsync (يولّد رقمًا جديدًا عند تعارض الرقم). الفهرس UX_RemedialTrackPublications_ActiveCode يستثني المحذوف. المحذوف يُعامَل كغير موجود في بوابة الوصول والقائمة والخطة والمحور والنبضات والاختبار والتقارير ولوحة المتابعة. تبويبا «النشطة/المحذوفة».
S9.2تعديل نموذجي الاختبار (SaveAxisExamsAsync) والفيديو (EditVideoAsync) بعد النشر مع تسجيل المنفّذ والقيم قبل/بعد، وتحذير بعدد الطلاب المنتظرين. مشاهدات الطلاب السابقة لا تُمس. بنية الخطة (إضافة/حذف/ترتيب) تبقى مقفلة.
S9.3بطاقة «آخر التعديلات» (≤ 20 صفًا) في Details.cshtml بربط الوسوم [RTK pub:id] و[RTK track:id] بلا أعمدة جديدة.

S10 — وضع مراجعة الفيديوهات (D24)

القصةما تم
S10.1أعمدة VideoReview* على RemedialTrackEnrollments + IsVideoReviewOpen.
S10.2SetVideoReviewAsync: فرد/محدّدون/الكل، معرّف غريب يرفض الطلب كله، حد 500، انتهاء مستقبلي ≤ 90 يومًا، تحديث مجمَّع بلا حلقة. الخادم يحسب الإتاحة لحظة الطلب؛ Locked لا يُراجَع؛ النبضات مرفوضة.
S10.3واجهة الأدمن في Details.cshtml: عمود المراجعة، تحديد متعدد، فتح/إغلاق للمحدّدين أو للجميع، تاريخ انتهاء بتوقيت السعودية. Action SetVideoReview بصلاحية ManageReview.
S10.4شريط «وضع المراجعة» في Axis.cshtml وحارس JS (data-review="1": لا نبضات ولا مؤقّت ولا إتمام). لا سياسة rtk-review منفصلة لأن العرض هو نفسه GetAxis.

S11 — تقارير ولي الأمر (D23، D28)

القصةما تم
S11.1RemedialTrackReportBuilder: دقائق المشاهدة لكل جولة (مقيّدة بمدة الفيديو)، المحاولات، PathKind، حد الاجتياز، والتوصية من RemedialTrackRecommendations (دالة نقية). عدد الاستعلامات ثابت.
S11.2كيان RemedialTrackParentReport (لقطة JSON ≤ 64KB) + AutoSendParentReports على أمر النشر. يُنشأ داخل معاملة OnExamSubmittedAsync (عدم الاجتياز) وFinalizeEnrollmentAsync (ختامي) مع إشعار فوري (SentAt UTC صريح). فهرس فريد (EnrollmentId, AxisProgressId, Kind). بلا ولي أمر ← NoParent بلا إشعار. فشل بناء اللقطة لا يُفشل التسليم.
S11.3Areas/Parents/.../RemedialTrackReportsController: قائمة/تفاصيل/إقرار بالاطلاع. الملكية من الخادم (غير المملوك/غير المُرسل/الموقوف/المحذوف ← 404). سياسة rtk-parent-report (60/دقيقة).
S11.4RemedialTrackParentCopy: نصوص مسؤولية ولي الأمر. عند فتح الإدارة للمحور التالي يصل إشعار نصي (قرار: بلا تقرير تابع).
